# Time Work Tracker

A local time-tracking app that records work sessions and exports an Excel workbook.

## Summary

This project is a practical productivity tool. It tracks work sessions by project and task, stores activity locally, supports editing and filtering, and exports a structured Excel workbook with summary sheets and charts.

## Features

- Start and stop one active timer at a time.
- Project boxes act as timer controls.
- Manual activity entry support.
- Edit and delete logged entries.
- Text and date-range filters.
- Local SQLite persistence.
- Excel export with activity log, project summary, daily summary, and dashboard sheets.

## Stack

- Python
- Flask
- SQLite
- JavaScript
- HTML and CSS
- Excel workbook generation

## What I Learned

- How to design a small CRUD workflow around real personal usage.
- How to preserve useful local data without needing cloud storage.
- How to export raw activity into a more recruiter-friendly report format.
