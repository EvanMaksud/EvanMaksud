## Featured Build

### [Dhaka Rainfall Risk](https://github.com/EvanMaksud/dhaka-rainfall-risk)

An end-to-end system that estimates next-day moderately-heavy-or-higher rainfall risk from 16 years of NASA POWER observations. It includes temporal validation, baseline comparisons, probability calibration, bootstrap uncertainty, versioned artifacts, a CLI, FastAPI, Docker, and CI.

`5,844 observations` · `25 features` · `731-day untouched holdout` · `12 tests` · `100/100 repository audit`

[Read the experiment log](https://github.com/EvanMaksud/dhaka-rainfall-risk/blob/main/EXPERIMENT_LOG.md) · [Inspect the model card](https://github.com/EvanMaksud/dhaka-rainfall-risk/blob/main/MODEL_CARD.md) · [View the evaluation](https://github.com/EvanMaksud/dhaka-rainfall-risk#holdout-results)
