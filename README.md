## About

I build practical Python projects around automation, computer vision, applied AI, and developer tooling. My focus is simple: make projects that a real person can run, inspect, and understand.

- I like turning messy workflows into small, useful tools.
- I care about readable code, clear READMEs, tests, and CLI design.
- I am building stronger public work around computer vision, data quality, route planning, and model experimentation.
- I am open to internships, junior developer roles, ML projects, and practical software collaborations.

## Featured Work

| Project | Focus | Why it matters |
| --- | --- | --- |
| [YOLO Dataset Auditor](https://github.com/EvanMaksud/yolo-dataset-auditor) | Computer vision, data quality, CLI | Finds missing labels, orphan labels, invalid class IDs, malformed YOLO rows, and class imbalance signals before model training. |
| [Repo Health Auditor](https://github.com/EvanMaksud/repo-health-auditor) | Developer tooling, testing, reporting | Scores whether a repository is ready to show publicly by checking docs, tests, packaging, CI, license, `.gitignore`, source layout, and secret risks. |
| [Flood Relief Route Planner](https://github.com/EvanMaksud/flood-relief-route-planner) | Graph search, logistics, real-world planning | Plans relief deliveries from supply hubs to shelters while avoiding blocked roads, penalizing risky roads, and prioritizing urgent unmet demand. |
| [Infinite Mouse Scroll](https://github.com/EvanMaksud/Infinite-Mouse-Scroll) | Windows automation, Python utility | Adds software momentum scrolling to a normal mouse using Python and the Windows API, with hotkeys and reverse-scroll braking. |
| [Object Detection YOLO11](https://github.com/EvanMaksud/Object-Detection-YOLO11) | YOLO11, OpenCV, PyTorch | Vehicle detection notebook with dataset inspection, training, transfer learning, learning curves, confusion matrix, and validation. |
| [Sentiment Analysis BERT](https://github.com/EvanMaksud/Sentiment-Analysis-BERT) | NLP, BERT, PyTorch | Multi-class emotion classification notebook with tokenization, dataloaders, model fine-tuning, and evaluation metrics. |
